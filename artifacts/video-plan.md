## Article Summary

Cursor has launched an SDK that allows developers to build programmatic coding agents using the same runtime and models that power Cursor's desktop app, CLI, and web app. The SDK enables teams to deploy agents to production quickly without building the entire agent stack from scratch. Agents can run locally, on self-hosted workers, or on Cursor's cloud infrastructure with dedicated VMs. Companies are using it for CI/CD automation, internal tooling, and even embedding agents into customer-facing products.

## Core Message

Cursor SDK brings production-grade coding agents to your codebase with just a few lines of TypeScript, eliminating the complexity of building agent infrastructure.
