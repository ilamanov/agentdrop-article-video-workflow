# Visual Style

Default visual style: clean startup explainer.

Images should be:

- simple
- readable
- metaphorical but grounded
- visually consistent across sections
- suitable for a 16:9 short explainer

Avoid:

- dense text inside images
- tiny UI details
- fake company logos unless the user explicitly asks
- photorealistic depictions of real people unless needed
- visual clutter

Each image prompt should include:

- subject
- setting
- visual metaphor
- composition
- mood
- aspect ratio
- style consistency phrase

Default style phrase:

Clean editorial illustration, modern software explainer, high contrast, simple shapes, crisp lighting, consistent color palette, no text, 16:9.
